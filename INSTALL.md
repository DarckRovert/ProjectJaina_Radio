# 📦 Guía de Instalación — ProjectJaina_Radio

1. Extrae o clona la carpeta `ProjectJaina_Radio` directamente en:
   ```text
   World of Warcraft\Interface\AddOns\ProjectJaina_Radio
   ```
2. Asegúrate de que contenga los archivos fundamentales:
   - `ProjectJaina_Radio.toc`
   - `ProjectJaina_Radio.lua`
3. Inicia el cliente de juego y comprueba que en las opciones de sonido de WoW la casilla "Música" esté activada para que el motor permita la reproducción de pistas.
4. Escribe `/radio` en el chat o haz clic en el icono orbital del minimapa para abrir el sintonizador.
